Getting started

How to use FinSight

Follow these simple steps to explore financial information.

1. Search for a company

On the Home page, type a ticker symbol such as AAPL, MSFT, or NVDA. Click Search.

2. Read the results

View the company's basic details, annual revenue and net income chart, and available insider transaction records.

3. Save companies

Click “Save company” to bookmark a ticker. This class-project version uses a shared saved list, not personal accounts.

4. If something does not load

Check the ticker symbol. Some StockFit endpoints require a paid subscription. A missing API token or unavailable database may also cause an error.

What is an insider transaction?

It's a reported transaction involving shares by a company's insiders, such as officers and directors. It is not automatically suspicious or illegal.
